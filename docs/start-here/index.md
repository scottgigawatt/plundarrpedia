# Choose your starting point

| Your goal | Guide | First result |
| --- | --- | --- |
| Use a VPN-protected downloader | [Privateerr quick start](../projects/privateerr/quick-start.md) | Three running containers and a working qBittorrent interface |
| Build your media automation stack | [Plundarr quick start](../projects/plundarr/quick-start.md) | Generated project, running services, and dashboard access |
| Run a smaller server or utility project | [Choose a preset](../projects/presets/index.md) | A focused Jellyfin, Plex, book, or utility deployment |

Start with the smallest result you need. You can progress from Privateerr to Plundarr, then [connect applications](../projects/plundarr/connect-applications.md) and add services. You do not need to read every guide before starting.

Use the [platform guide](../guides/index.md) for Synology, TrueNAS, or ordinary Docker. [How the containers connect](architecture.md) explains the setup without being a prerequisite.
