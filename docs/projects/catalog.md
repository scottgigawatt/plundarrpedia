# Media project catalog

Use this catalog to understand where each repository fits in the self-hosted
media ecosystem. Follow the repository link for current releases and exact
configuration; use Plundarrpedia for cross-project workflows and explanations.

## Media stacks

| Project                                                                         | Identity                  | Purpose                                                          |
| ------------------------------------------------------------------------------- | ------------------------- | ---------------------------------------------------------------- |
| [Plundarr](https://github.com/scottgigawatt/plundarr)                           | Pirate fleet              | Generates a complete media automation Compose stack.             |
| [Boudoirr](https://github.com/scottgigawatt/boudoirr)                           | Steamy late-night stack   | A Whisparr-centered sibling stack with torrent and Usenet lanes. |
| [Duplex](https://github.com/scottgigawatt/duplex)                               | Backstage production crew | Plex curation, cleanup, monitoring, notifications, and updates.  |
| [Jellyfin](https://github.com/scottgigawatt/jellyfin)                           | Private media reef        | A focused Jellyfin Docker Compose deployment.                    |
| [Calibre Web Automated](https://github.com/scottgigawatt/calibre-web-automated) | Genteel library           | Automated ebook intake, metadata, and browser-based reading.     |

## Infrastructure and configuration
